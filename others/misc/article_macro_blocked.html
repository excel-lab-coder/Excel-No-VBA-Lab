「マクロの実行がブロックされました」と表示されたとき

インターネットやメールから受け取ったファイルを開いたときに出る「マクロの実行がブロックされました」の意味と、Microsoftの公式の案内に書かれている対応だけをまとめます。マクロを許可してよいかは、必ず社内規程と情報システム部門の判断を確認してください。

⚠️ まず確認してください

マクロの実行を許可してよいかは、会社のルールで決まります。
この表示は、インターネットやメールから受け取ったファイルのマクロを、Microsoftが既定で止めているために出ます。マクロは便利な一方、悪意のあるプログラムの入り口にもなります。社内規程と情報システム部門の判断を必ず確認し、許可されていない場合は以下の操作をしないでください。

この記事は、Microsoftの公式の案内に書かれている手順だけを紹介します。会社のPCでは、管理者の設定（グループ ポリシーなど）により、ここに書いた操作ができない場合があります。

表示の意味

Excelなどでファイルを開いたときに、「セキュリティ リスク　このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました。」という赤い帯が表示されることがあります。

インターネットからダウンロードしたファイルやメールの添付ファイルには、Windowsが「インターネットから来たファイル」という印を付けます。Officeはこの印が付いたファイルのマクロを、既定で実行しないようになっています。

Microsoftの公式の案内にある対応

ファイルの送り主と内容が信頼でき、社内のルールで許可されている場合に限り、Microsoftは次のような方法を案内しています。

方法1：ファイルのプロパティで「許可する」にチェックを入れる

  1. ファイルを閉じ、パソコン内のフォルダ（デスクトップなど）に保存します。
  2. エクスプローラーでファイルを右クリックし、「プロパティ」を開きます。
  3. 「全般」タブの下にある「セキュリティ」の「許可する」にチェックを入れて「OK」を押します。
  4. ファイルを開き直します。

「許可する」の表示は、環境により結果が異なる場合があります。表示されない場合は、管理者の設定で変更できないようになっていることがあります。

方法2：信頼できる場所・信頼済みサイトを使う

社内のファイルサーバーなど、会社が信頼できると決めた場所を「信頼できる場所」や「信頼済みサイト」に登録する方法もあります。これは組織のセキュリティ全体に関わる設定なので、個人で設定せず、情報システム部門に相談してください。

詳しくは Microsoft の公式ページ インターネットからのマクロは既定でブロックされます を確認してください。

してはいけないこと

  • 送り主が分からないファイル、急いで開くよう求めるメールの添付ファイルのマクロを許可する。
  • 社内で禁止されているのに、マクロのセキュリティ設定を自分で緩める。
  • 「すべてのマクロを有効にする」のような設定にする。

マクロを使わずに同じことをしたい場合

マクロが許可されない職場でも、Excelの標準機能で代わりができることがあります。

  • データの取り込み・整形の繰り返し → Power Query
  • 条件に合うデータの抽出・集計 → 関数（FILTER・XLOOKUP・SUMIFSなど）
  • 入力作業の自動化 → QRリーダー連携
  • 困りごとから探す → お悩み別索引
