Windows 10で画面録画する方法の比較：追加インストールなしで使える4つの方法

ソフトの追加インストールができない職場で、Windows 10のPCから操作手順を動画にしたいときの選び方です。PowerPoint・Xbox Game Bar・スニッピング ツール・Teams等を、範囲指定、デスクトップを録れるか、音声、保存形式で比べます。

Windows 10 は2025年10月14日にMicrosoftのサポートが終了しています。セキュリティ更新が届かない状態のPCは、社内の方針を確認してから使ってください。Windows 11 の場合は スニッピング ツールで画面録画する方法 も使えます。

💡 この記事の結論

Windows 10なら、PowerPointの「画面録画」が手軽です。Windows 11なら、スニッピング ツールが使えます。
どちらも追加インストールが要らない標準機能なので、ソフトの導入申請ができない職場でも試しやすい方法です。
  • Windows 10：PowerPointの「挿入 → 画面録画」 → 手順はこちら
  • Windows 11：スニッピング ツールの録画（Windows+Shift+R） → 手順はこちら
  • ナレーション付きの説明動画：PowerPointの「スライドショーの記録」 → 手順はこちら

PowerPointの画面録画（Windows 10の第一候補）

PowerPointの「挿入」タブにある「画面録画」を使うと、画面の一部を四角で選んで録画できます。録画した動画はスライドに貼り付けられ、右クリックの「メディアに名前を付けて保存」でMP4ファイルとして取り出せます。

デスクトップやエクスプローラーも録れるので、「どのフォルダのどのファイルを開くか」から説明したいときにも向いています。

詳しい手順は PowerPointの画面録画で操作マニュアル動画を作る にまとめています。

Xbox Game Bar（ゲーム用の録画機能）

Windows 10に最初から入っている録画機能です。Windows+G で開き、Windows+Alt+R で録画の開始・停止ができます。

注意：デスクトップとエクスプローラーは録画できません。
Game Barは「1つのアプリの画面」を録る機能です。Excelの操作だけなら録れますが、フォルダを開く操作や、複数のアプリをまたぐ手順は途中で録れなくなります。会社PCではGame Bar自体が無効にされていることもあります。

スニッピング ツール（Windows 11のみ）

Windows 11のスニッピング ツールには録画機能があります。Windows 10のスニッピング ツールには録画機能がないため、Windows 10ではPowerPointかGame Barを使います。

手順は Windows 11 スニッピングツールで画面録画する方法 を見てください。

Teams・Streamなど（会社が使っている場合）

会議の録画や、Microsoft 365のStreamなどの録画機能が使える職場もあります。ただし、保存先がクラウドになる、録画できる人が管理者の設定で決まっている、といった違いがあります。使える範囲は社内のルールと管理者の設定で確認してください。

「ステップ記録ツール（psr）」は新しく勧めません

Windowsの「ステップ記録ツール」は、操作を画像付きで記録できる便利な機能でしたが、Microsoftは非推奨（今後のリリースで削除予定）としています。これから手順書や動画を作るなら、ここで紹介した録画の方法を使う方が安心です。

Windows 10のサポート状況について

Windows 10のサポートは 2025年10月14日 に終了しました。期間を区切ってセキュリティ更新を受けられる延長セキュリティ更新（ESU）プログラムがありますが、期間や条件は契約の形によって異なります。会社PCの更新予定は情報システム部門に確認してください。

よくある質問

会社のPCで画面録画をしてもよいですか？

社内規程で画面録画や動画の持ち出しが禁止されていることがあります。録画を始める前に、規程と上司・情報システム部門の判断を確認してください。標準機能であることと、業務で使ってよいことは別の話です。

個人情報が映り込まないか心配です

録画の前に、メール・チャットの通知を止め、関係ないウィンドウを閉じ、テスト用のデータに切り替えてください。範囲指定ができる方法（PowerPoint・スニッピング ツール）で、必要な部分だけを録るのも有効です。録画後は、共有する前に最初から最後まで再生して確認します。
