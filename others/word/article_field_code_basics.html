Wordフィールドコード入門：Alt+F9・Ctrl+F9の基本と差し込みでの使い方

Word差し込み印刷のフィールドコードを、Alt+F9・Ctrl+F9・F9の3つのキーから説明します。書式スイッチ、条件分岐、次のレコード、連名まで、目的別の応用記事への入口です。

結論

Alt＋F9で見る、Ctrl＋F9でかっこを入れる、F9で更新する。この3つで操作できます。かっこは必ずCtrl＋F9で入れます。

やや難（Lv.4）／ 通常の操作で足りる場合は基本記事を先に読んでください

  1. コードを見る
  2. スイッチを足す
  3. F9で更新
  4. 完成文書で確認
目次

使うキーは3つです

キーできること覚え方
Alt＋F9文書全体のコード表示と結果表示を切り替える«氏名» が { MERGEFIELD 氏名 } に変わります。もう一度押すと戻ります。
Ctrl＋F9フィールド用の「{ }」を入れるキーボードの波かっこでは動きません。必ずこのキーで入れます。
F9選んだフィールドを更新する書き換えた後に押すと結果に反映されます。

手順1既存のフィールドを見る

  1. 差し込みフィールドを入れた文書で「結果のプレビュー」をオフにします。
  2. Alt＋F9 を押し、{ MERGEFIELD 氏名 } のような表示を確認します。
  3. もう一度押して元に戻します。これだけなら文書は変わりません。

手順2スイッチを足して更新する

  1. { MERGEFIELD 日付 } の列名の後ろに、半角スペースと \@ "yyyy年M月d日" を入力します。かっこは作り直しません。
  2. フィールドを選んで F9 を押します。
  3. プレビューだけでなく、完成文書へ出力して全員分の結果を確認します。

入力で間違えやすいところ

  • 「{ }」の中に入力したら、→ を2回押すと閉じかっこの外に出られます（1回だとまだ中にいます）。
  • 「"」は半角で入力します。全角の「”」や、自動で変わった「“ ”」では動きません。
  • =、<>、> の前後には半角スペースを入れます。
  • 「\」はWordの画面では「¥」に見える場合があります。
  • 間違えたら Ctrl＋Z で戻せます。
  • コードがそのまま印刷される場合は、Alt＋F9 で表示を戻します。

目的別：どのフィールドを使うか

やりたいこと使うもの記事
郵便番号・日付・金額の見た目を変える\#、\@、\* DBCHAR書式スイッチ実例集
条件で文面や対象者を変えるIF、SKIPIFIf…Then…ElseとSkipIf
1枚に複数人を自分で配置するNEXT、MERGEREC次のレコードの手動配置
