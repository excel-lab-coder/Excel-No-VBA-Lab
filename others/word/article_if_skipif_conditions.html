Word差し込みで条件によって文面や対象者を変える：If…Then…ElseとSkipIf

Word差し込み印刷で、部署ごとに文面を変えるIf…Then…Elseと、条件に合う人を飛ばすSKIPIFを実例で説明します。次のレコードと併用してはいけない理由も整理します。

結論

文面を変えるならIF、対象者を外すならフィルターが基本です。SKIPIFも動きますが、次のレコードを使う文書では併用しません。

難しい（Lv.5）／ 通常の操作で足りる場合は基本記事を先に読んでください

  1. 条件を決める
  2. ルールを挿入
  3. プレビュー
  4. 完成文書で確認
目次
  1. 文面を変える：If…Then…Else
  2. 応用：空の枠に固定文字を残さない
  3. 対象者を飛ばす：SKIPIF

文面を変える：If…Then…Else

  1. 文字を出し分けたい位置をクリックします。
  2. 「差し込み文書」→「ルール」→「If…Then…Else」を選びます。
  3. フィールド名、比較、比較対象を指定し、一致するときと一致しないときの文字を入力します。
  4. 「結果のプレビュー」で切り替え、完成文書で全員分を確認します。

コードでは次の形になります。

{ IF { MERGEFIELD 対象 } = "○" "対象" "対象外" }
実際に差し込んだ結果
名簿の「対象」結果
○対象
（空欄）対象外

応用：空の枠に固定文字を残さない

ラベルの余り枠に「様」だけが残るときは、氏名があるときだけ「様」を出します。「ルール」→「If…Then…Else」で次のように設定します。

  • フィールド名：氏名
  • 比較：「が値と等しくない」（版によって「等しくない」）
  • 比較対象：（空欄）
  • 一致する場合の文字列：様
  • 一致しない場合の文字列：（空欄）

枠ごとに設定が増えるので、完成文書で余り枠を消す方法で足りることがほとんどです。

対象者を飛ばす：SKIPIF

条件に合う人を、差し込みの対象から外します。

{ SKIPIF { MERGEFIELD 部署 } = "総務部" }

3人の名簿（営業部・総務部・経理部）を名簿形式で差し込むと、総務部の人が飛ばされ、2人だけが出力されました。

次のレコードと併用しません。NEXTを使う複数人配置の文書では、SkipIfを併用しません。対象者は「アドレス帳の編集」のチェックやフィルターで先に決め、完成文書で人数と順番を確認します。

対象者を外すだけなら、条件が残って見えるWordのフィルターの方が、引き継ぎやすい方法です。

2026年11月3日に、Windows版Word（バージョン16.0）で架空のデータをExcelからつないで差し込み、結果を確認しました。紙への印刷は行っていません。環境により結果が異なる場合があります。
