Word差し込み印刷で郵便番号と日付を整える方法

郵便番号をハイフン付きに、日付を「2026年11月2日」の形にそろえます。Excelで印刷用の列を作り、Wordではその列を選ぶだけです。

結論

Excelで =IF(A2="","",TEXT(A2,"000-0000")) のような印刷用列を作り、Wordではその列を選びます。元の列は残します。

  2. TEXT列を作る
  3. 列を選び直す
  4. 完成文書で照合

なぜExcel側で整えるのか

Excelのセルの見た目は、Wordへ渡りません（理由は金額・割合・番号の記事で説明しています）。元の列を残し、TEXT関数で印刷用の列を作って、その列をWordへ挿入します。フィールドコードの編集は不要です。

手順1元データの形を確認する

  • 郵便番号がハイフンなしの7桁数値か、すでにハイフン付きの文字列かを確認します。1列の中で数値と文字列を混ぜないよう、先にそろえます（住所録の作り方）。
  • 日付の計算・抽出には元の日付列を使います。TEXT関数の結果は表示用の文字列なので、元の列を置き換えません。

手順2印刷用の見出しと式を入力する

元データと印刷用列の対応
元の列元の値新しい列名2行目に入れる式印刷用の結果
A列：郵便番号10001郵便番号_印刷用=IF(A2="","",TEXT(A2,"000-0000"))001-0001
C列：案内日2026/11/2案内日_印刷用=IF(C2="","",TEXT(C2,"yyyy年m月d日"))2026年11月2日
  1. 表の右側に空いている列を用意し、1行目へ表の「新しい列名」を入力します。
  2. 同じ列の2行目へ式を入れます。式の中のA2やC2は、実際の元データのセルに合わせます。
  3. Enterを押して結果を見ます。式自体が表示される場合は、その列の表示形式を「標準」にしてからF2、Enterで確定し直します。
  4. セル右下の四角を最終行までドラッグし、全員分へ式をコピーします。

確認空欄が空欄のままで、先頭・途中・最後の結果が正しければ保存します。

手順3Wordで「印刷用」の列を選び直す

  1. Excelを保存し、Wordのひな形につなぎ直します（接続の手順）。完成文書ではなく、元のひな形で作業します。
  2. 元の「郵便番号」「案内日」のフィールドを選んで削除します。
  3. 同じ場所をクリックし、「差し込みフィールドの挿入」で「郵便番号_印刷用」「案内日_印刷用」を選びます。

確認「結果のプレビュー」で、001-0001 や 2026年11月2日 の形になれば成功です。

手順4完成文書で確認する

「完了と差し込み」→「個々のドキュメントの編集」→「すべて」で完成文書を出し、先頭と最後の人を確認します。ひな形と完成文書は別の名前で保存します。

うまくいかないとき

印刷用列の確認表
症状確認すること
郵便番号が000-0000になる空欄を0としてTEXTへ渡していないか。空欄を残すIF付きの式を使います。
ハイフン付きの番号で式がうまく動かないTEXTの7桁数値用の例を、ハイフン付き文字列に流用していないか。
日付が意図しない日になる元データが日付値かを確認します。曖昧な月日表記の文字列は、元資料を見て日付を確定します。
Wordの列一覧に新しい列がないExcelを保存したか、正しいファイル・シートにつないでいるかを確認します。

金額・割合・顧客番号を整える場合は、金額・割合・番号の表示崩れを直す方法を見てください。

Excelに列を足せない場合書式スイッチ実例集（Wordのフィールドコードで表示を変える）難易度 Lv.5
