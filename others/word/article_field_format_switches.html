Word差し込みの書式スイッチ実例集：郵便番号・日付・和暦・金額・全角

Excelに印刷用列を足せないときのWord書式スイッチを、実際に差し込んだ結果とともに整理します。郵便番号、日付、和暦、金額、先頭ゼロ、DBCHARと、割合など失敗する例も載せています。

結論

日付は \@、数値は \#、全角は \* DBCHAR です。ただし文字列に \# を付けると壊れ、割合は8%になりません。Excelに列を足せるなら、そちらが確実です。

難しい（Lv.5）／ 通常の操作で足りる場合は基本記事を先に読んでください

  2. スイッチを追加
  3. F9で更新
  4. 完成文書で確認

この記事を使う場面

元のExcelに印刷用列を追加できないときの方法です。列を追加できるなら、郵便番号と日付・金額と数値の記事の方法を使います。フィールドコードの操作は入門記事で説明しています。

設定の手順

  1. 「結果のプレビュー」をオフにし、対象の差し込みフィールドを右クリックして「フィールドコードの表示/非表示」を選びます。
  2. すでにあるMERGEFIELDの列名の後ろへ、半角スペースと表示指定を追加します。かっこは作り直しません。
  3. もう一度右クリックで通常表示へ戻し、フィールドを選んでF9で更新します。
  4. プレビューだけでなく完成文書へ出力して、空欄・0・先頭ゼロを含む結果を確認します。

実際に差し込んだ結果

Excelの列をWordにつないで差し込んだ結果です。同じ値でも、スイッチの有無と元の値の形で結果が変わります。

実際に起きた失敗

やったこと結果対処
ハイフン付きの文字列「100-0001」に \# "000'-'0000" を付ける000-0099 になるすでに整っている文字列にはスイッチを付けません。数値の列にだけ使います。
税率0.08をそのまま差し込む8.0000000000000002E-2 になるExcelの印刷用列で =TEXT(G2,"0%") を作ります。
税率0.08に \# "0%" を付ける0% になる（8%にならない）Wordは0.08を100倍しません。同じくExcelの印刷用列を使います。
数字が横に寝る縦書きで半角の数字が横向きになる郵便番号・住所のフィールドに \* DBCHAR を付け、F9で更新します。
DBCHARを付けたのに変わらない結果が全角にならない「\」と「*」の間に空白がないか、「DBCHAR」が半角の英字かを確認します。
金額0に \# "#,##0" を付ける前に空白が入った「 0」になる列をそろえたくない場合は、0の表示を決めた3区分の形（表の「0を別表示」）を使います。

列名が違う場合

「MERGEFIELD」の後ろは、Excelの見出しと同じ名前にします。見出しが違えば、ここだけを置き換えます。

  • { MERGEFIELD 〒 \# "000'-'0000" }
  • { MERGEFIELD 郵便番号1 \# "000'-'0000" }
  • { MERGEFIELD zip \# "000'-'0000" }

日付の月は大文字の M です。小文字の m は分を表します。

割合を表示したいとき

割合はExcelと同じ扱いにしないでください。Wordで0.08に \# "0%" を付けるだけでは8%になりません。通常は上のExcelのTEXT列を使います。Word内だけで計算するなら100倍する計算フィールドと数値書式の両方が必要になり、入れ子のフィールドが増えるため、この記事の基本手順には含めません。

縦書きで数字が横に寝るとき：DBCHAR

「結果のプレビュー」をオンにすると、住所録の半角の数字やハイフンが、縦書きの中で横向きに寝て表示されました。

住所録の数字を全角に直す方法もありますが、Word側で差し込むときだけ全角に変えることができます。フィールドに \* DBCHAR（全角文字に変換する書式スイッチ）を付けます。

  1. テキストボックスの中をクリックし、Alt+F9 でフィールドコードを表示します。
  2. 郵便番号・住所_1・住所_2のフィールドの、列名の後ろに \* DBCHAR を入力します。
  3. Alt+F9 で表示を戻し、テキストボックスの中を全部選んで F9 を押して更新します。
{ MERGEFIELD 郵便番号 \* DBCHAR }
{ MERGEFIELD 住所_1 \* DBCHAR }
{ MERGEFIELD 住所_2 \* DBCHAR }

フィールドコードは上のコード欄で全文を確認できます。「\」はWordの画面では「¥」に見える場合があります。

更新すると、数字が全角になり、縦に並びました（長形3号の封筒の記事の冒頭の画面）。

  • ハイフンは全角の「－」になり、縦書きの中では横棒で表示されました。番地の区切りを縦棒にしたい場合や、「一－二－三」のような漢数字にしたい場合は、住所録の側で書き方を変えます。
  • 撮影した例では、住所_2や会社が空の人も、その行のぶんの空きは表示されず、詰めて表示されました。
