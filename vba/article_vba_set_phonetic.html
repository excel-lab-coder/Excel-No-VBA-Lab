VBAでふりがなをまとめて付ける：CSVや貼り付けた名簿をSetPhoneticで処理

CSVや貼り付けた氏名データには読みの情報がないため、PHONETIC関数を使っても漢字のまま返ります。VBAの SetPhonetic を使うと、読みを推定してまとめて生成できます。この記事では、仕組みと手順に加えて、どんな場合に使ってよく、どんな場合に使うべきでないかを説明します。

⚠️ 重要：自動生成されるフリガナは推定結果です
SetPhoneticは漢字から一般的な読みを生成しますが、本人の正式なフリガナを保証する機能ではありません。特に氏名・地名・固有名詞では、誤った読みが生成される場合があります。宛名印刷、各種申請書、名寄せ、顧客管理などに使う場合は、本人の申告や元資料と照合してください。元のシステムに正式なフリガナが保存されている場合は、その情報を優先してください。
💡 本編（VBAなし）との位置づけ

この記事は、VBAの使用が許可されている環境向けです。VBAが使えない環境では、PHONETIC関数でフリガナを取り出すの方法を使ってください。

2. 読みのない漢字から生成できる理由

CSVには文字だけが入っていて、読みの情報はありません。それでもふりがなを付けられるのは、元の読みを取り出しているのではなく、文字列から読みを新しく推定して作っているからです。似た名前の3つの機能は、役割が違います。

3つの機能の違い
機能やっていること読みのないCSVの「山田太郎」
PHONETIC 関数セルに保存されたふりがな情報を取り出す「山田太郎」のまま返る
Range.SetPhoneticセルにふりがな情報を作る読みが作られ、PHONETICで「ヤマダタロウ」と取り出せるようになる
Application.GetPhonetic文字列から読みの候補を取得する（セルは変えない）「ヤマダタロウ」という文字列を返す

推定なので、読みが複数ある氏名では、本人の読みと違う結果になることがあります。次は検証環境での結果です。別の環境でも同じ読みになるとは限りません。

読みが複数ある氏名の生成結果
氏名の漢字考えられる読みの例検証環境で生成された読み
角田カクタ、ツノダ、カドタカクタ
海野ウミノ、ウンノウンノ
東海林ショウジ、トウカイリントウカイリン
和子カズコ、ワコカズコ

読みを決める辞書や仕組みは、Microsoftの資料には書かれていません。検証環境：Windows版 Excel（バージョン16.0、ビルド20625）、2026年11月4日。

5. イミディエイトウィンドウで実行する

この方法は「マクロを使わない方法」ではなく、マクロを登録・保存せずにVBAの命令を実行する方法です。

イミディエイトウィンドウのメリットと制約
メリット制約
標準モジュールを作らなくてよいVBAの実行にあたる。VBA禁止の社内規則を回避する手段ではない
1行の命令をその場で実行できる実行後は「元に戻す」が使えなくなる（検証環境で確認）
実行用のコードをブックに保存しなくてよい選択範囲を間違えると、対象外のセルにも読みが付く
結果を通常の .xlsx で保存できる（検証環境で警告なし）複雑な処理や継続運用には、通常のVBAマクロが適している
単発の一括処理に向いている実行した内容が記録に残らない

手順

  1. ブックをコピーして、コピーのほうを開きます。原本は変更しません。
  2. 読みを付ける氏名のセルだけを選びます。見出しを含めると、見出しにも読みが付きます。
  3. Alt+F11 でVBEを開き、Ctrl+G でイミディエイトウィンドウを開きます。
  4. 次の1行を入力し、その行で Enter を押します。
Selection.SetPhonetic

シートに戻り、隣の列で =PHONETIC(A2) を使うと、生成された読みを確認できます。

6. 確認済みの読みを守る

Microsoftの説明では、指定した範囲にある既存のふりがなは、新しいものに上書き（削除）されます。本人確認済みの読みが入った名簿に実行すると、その情報が失われるおそれがあります。

検証環境では、既存の読みは残り、読みのない部分だけが補われました（例：「和子」の「ワコ」はそのまま、「山田」だけ「アイウ」と登録した「山田太郎」は「アイウタロウ」）。ただし公式の説明と異なり、版や環境によって変わる可能性があります。上書きされる前提で作業してください。

  1. 原本は変更せず、コピーで作業します。
  2. 正式な読みが保存されている列は、対象から外します。
  3. 読みを生成する行を、新しく取り込んだ行などに限定します。
  4. 生成した読みは、別の列で元の値と比べて確認します。
  5. 確認済みの読みと推定の読みを、同じ列に混在させません。

対象の候補を探す簡易的な式

=IF(PHONETIC(A2)=A2,"要確認","")

読みが未設定の可能性がある候補を拾う式です。読みの有無を厳密に判定するものではありません。この式だけを根拠に、上書きしてよいと判断しないでください。

簡易的な式の結果
セルの状態結果実際
読みのない漢字要確認正しく拾える
読みのある漢字空欄正しく除外できる
カタカナだけ要確認読みがなくても問題ないのに拾う
読みが一部だけ（ヤマダ太郎）空欄未完成なのに拾えない
ひらがなだけ空欄PHONETICがカタカナで返すため一致しない
数値・数式空欄PHONETICが空欄を返すため一致しない

7. フィルターで絞った行だけに実行する

⚠️ フィルターで隠れた行も対象になります
検証環境では、Selection.SetPhonetic は、選択範囲の中でフィルターで隠れている行にも読みを付けました。

見えている行だけにするには、次の1行を使います。氏名の範囲を2セル以上選んでから実行します。

Selection.SpecialCells(xlCellTypeVisible).SetPhonetic

検証環境では、イミディエイトウィンドウで実行でき、隠れた行には読みが付きませんでした。変数の宣言も繰り返しも要らないので、次のような書き方より誤操作が少なくなります。

For Each c In Selection.SpecialCells(xlCellTypeVisible): c.SetPhonetic: Next

こちらも同じ結果でした。イミディエイトウィンドウでは Dim は使えませんが、宣言なしの変数 c で動きました。

空白・数値・数式・エラーのセルが範囲に混ざっていても、エラーにはならず、読みも付きませんでした。文字列の結果を返す数式のセルにも読みは付きません。値に変換してから実行します。

8. 元のふりがな情報を変更せず、別列に推定読みを生成する

GetPhonetic は、文字列から読みの候補を新しく取得する命令です。セルに保存された読みを読み取るものではありません。実際に、セルに「ワコ」と登録した「和子」でも、検証環境の GetPhonetic("和子") は「カズコ」を返しました。セルのふりがなは変わらないので、推定の読みを別の列で確認したいときに向いています。

For Each c In Selection: c.Offset(0, 1).Value = Application.GetPhonetic(c.Value): Next

選んだセルの1つ右の列に、読みを書き込みます。

実行時の注意（検証環境の結果）
状況起きること対策
右の列にデータがある確認なしで上書きされる先に空の列を挿入する
フィルターで隠れた行隠れた行の右の列にも書き込まれるフィルターを解除するか、選択を分ける
エラーのセル（#N/A など）実行時エラー13で止まる。それより上の行だけ書き込まれた状態になる実行前にエラーを解消する
数値全角の数字として取得される（セルに書くと数値に戻る）氏名の列だけを選ぶ
英数字「Smith」は「Ｓｍｉｔｈ」のように全角になる結果を確認する
空白セル空欄のまま特になし
複数の読みがある氏名検証した氏名では、候補は1つだけ返った候補の順番や数に頼らない

GetPhonetic は、Officeの言語設定で日本語が選択またはインストールされている場合にだけ使えます。

9. ひらがな・カタカナ・半角に切り替える

生成した読みの種類をまとめて変更できます。PHONETIC関数の結果も、この設定に従います。

Selection.Phonetics.CharacterType = xlHiragana
指定できる種類
定数値種類検証環境の結果
xlKatakana1全角カタカナヤマダタロウ
xlKatakanaHalf0半角カタカナﾔﾏﾀﾞﾀﾛｳ
xlHiragana2ひらがなやまだたろう
xlNoConversion3変換なしエラー（設定できず）

セルの上にふりがなを表示して確認するには、次の1行を実行します。元に戻すときは False にします。

Selection.Phonetics.Visible = True
  • Phonetics と Phonetic：Phonetics は範囲内のふりがな全体です。Range.Phonetic は以前の版との互換のためのプロパティなので、この記事では Phonetics を使います。
  • 隠れた行：どちらの命令も、フィルターで隠れた行を含む選択範囲全体に効きます。
  • 読みのないセル：検証環境ではエラーにならず、何も変わりませんでした。

10. 業務で使うときの注意

生成した読みは、「推定読み」として扱い、「本人確認済みの読み」と区別します。

推定読みの使い分け
用途推定読みの扱い
名簿の検索補助、仮の並べ替え使える。「仮」であることが分かるようにする
顧客名簿・従業員名簿への登録そのまま登録しない。元資料や本人の申告と照合してから
郵送用の宛名照合してから使う
行政手続きで使う氏名情報使わない。本人の申告や正式な資料の読みを使う
氏名をキーとした名寄せ使わない。読みが同じでも同一人物とは限らず、番号など別の項目で照合する

確認済みの読みは列にして残す

CSVは文字だけの形式なので、ふりがな情報は保存されません（検証環境でも、CSVに保存して開き直すと読みは消えました）。残したい読みは、セルのふりがなに頼らず、独立した列に保存します。

  1. 「推定読み」の列を作り、=PHONETIC(A2) の結果を値として貼り付けます。
  2. 照合が終わった読みだけを、「確認済みの読み」の列に入れます。
  3. 他のシステムやCSVに渡すときは、「確認済みの読み」の列を使います。

カタカナ・半角・ひらがなへの変換は、PHONETIC関数の記事で説明しています。
