# Word操作画像の読みやすさ・表示寸法の修正（2026-11-02）

Windows版Wordの実画面を撮影したPNGです。生成AIによる画面再現・画像の引き伸ばしはしていません。氏名・住所・会社は撮影用の架空データです。

|---|---|

|three-label-preview.png|Word 100％。同じ1列3段の表に山田・佐藤・鈴木の3名を差し込んだ表示。各段の本文を順に切り出して配置。|

本文・フィールドの文字や順番は変更していません。複数の切り抜きを並べた画像は、実際の用紙の余白・寸法を示すものではない旨を記事のキャプションにも記載しました。紙への印刷は行っていません。

元文書・切り出し前の画面は非公開の `_dev/word-image-retakes/`、`_dev/article-screenshots/` にあります。

あわせて `../word-guide/` のPNGという名前のJPEG 7点を実際のPNG形式へ統一し、貼り付け記事2箇所の異常なwidth/heightを修正しました。画面全体を縮小していた旧ラベル画像を上記へ差し替え、途中で切れていた連名ラベル・封筒のコード画像2点は本文のコード欄への参照に変更しています。

Word記事の画像は実寸を超えて引き伸ばさず、縦横比を保ち、縦長画像は本文中で高さ740pxまでとします。遅延読み込み前にも正しい表示領域を確保します。クリック時のビューアーは「画面に合わせる」「原寸で読む」を切り替えられ、原寸表示では縦横にスクロールできます。JavaScriptを無効にした場合も通常の画像リンクが使えます。

`node scripts/verify-site.cjs` は実ファイルのPNG/JPEG署名から寸法を取得し、Word記事のwidth/height・拡張子・代替テキストを確認します。
