UNIQUE×FILTER×SORT：条件付きリストをきれいに並び替える

前回は、UNIQUE関数とFILTER関数を組み合わせて「条件付きの重複なしリスト」を作りました。ただ、そのままだと元データの出現順で並ぶため、担当者名や商品名の一覧としては少し見づらいことがあります。

リード文：順番がバラバラで見にくい悩み

前回の記事で作った =UNIQUE(FILTER('担当者一覧'!C3:C14,'担当者一覧'!D3:D14="対象")) は、条件に合うデータだけから重複なしリストを作れる便利な式です。

ただし、結果は元データに出てきた順番のままです。担当者一覧や商品一覧として使うなら、あいうえお順や昇順で整っていた方が読みやすくなります。そこで今回の主役が SORT関数 です。

結論：3つの関数をネストした数式

条件で絞り、重複を消し、最後に並び替える式は次の形です。

=SORT(UNIQUE(FILTER('担当者一覧'!C3:C14,'担当者一覧'!D3:D14="対象")))

これで、次の3つの作業がすべて自動になります。

この1行で完了する作業
FILTER：「担当者一覧」シートの対象区分が「対象」のデータだけに絞る。
UNIQUE：絞った結果から重複をなくす。
SORT：残ったリストをあいうえお順・昇順で並べる。

SORT関数の基本とネストの構造

SORT関数は、配列を並び替える関数です。基本構文は次の通りです。

=SORT(配列, [並べ替えインデックス], [並べ替え順序])

引数を省略した場合、先頭列を基準に昇順で並び替えます。文字ならあいうえお順やA→Z、数値なら小さい順です。

関数は内側から順番に処理される

3つの関数が重なると難しく見えますが、処理順序は内側から外側です。

処理順序
順番関数役割
1FILTERまず、条件に合うものだけを集める
2UNIQUE次に、その中からダブりを消す
3SORT最後に、残ったリストをきれいに並び替える
=SORT( UNIQUE( FILTER('担当者一覧'!C3:C14,'担当者一覧'!D3:D14="対象") ) )

上のように改行して見ると、内側から順に処理されるイメージがつかみやすくなります。

降順にしたい場合

SORT関数は、第3引数に -1 を指定すると降順になります。文字ならZ→A、数値なら大きい順です。

=SORT(UNIQUE(FILTER('担当者一覧'!C3:C14,'担当者一覧'!D3:D14="対象")),1,-1)

第2引数の 1 は「1列目を基準にする」という指定です。今回のように1列のリストを並べる場合は、1列目を基準にすればOKです。

昇順と降順の使い分け
担当者名や商品名の一覧なら省略形の昇順が読みやすいことが多いです。売上額や件数のような数値ランキングなら、-1 の降順が向いています。

実務補足：日付列の表示を整えて並び替える

Excelの日付は、内部では日付シリアル値という数値として保存されています。セルに見えている「2026年6月1日」などの表記は表示形式によるものです。

FILTER・UNIQUE・SORTで作った一覧の日付を決まった見た目にそろえるには、日付値のまま抽出・重複削除・並び替えを済ませ、最後にTEXT関数で文字列化します。この順番なら、表示を整えながら日付としての正しい並び順も保てます。

日付値で並べてから、表示を整える
先にTEXT関数で文字列化すると、月日が1桁と2桁で混在したときに文字列順で並ぶことがあります。正確な日付順が必要なら、元の日付値でSORTを行い、最後に表示用の文字列へ変換するのが安全です。
DATEVALUEやDATEの結果を文字列へ置き換えない
日付シリアル値は、並び替え、検索、期間抽出に必要です。計算用の日付列はそのまま残し、Word差し込み印刷や配布用データには別の「日付_表示用」列を用意します。後工程の担当者が表示形式やフィールドコードで悩まない形にして渡すことも、実務設計の一部です。

日付1列を抽出・重複削除・並び替えする

C列が日付、D列が抽出条件なら、日付値のまま重複を消して並び替え、最後にTEXT関数で表示用の文字列へ変換します。

=TEXT(SORT(UNIQUE(FILTER('申込一覧'!C3:C14,'申込一覧'!D3:D14="対象"))),"yyyy年m月d日")

関数は内側から、FILTERで抽出→UNIQUEで重複削除→SORTで日付順に並び替え→TEXTで「年月日」の文字列へ変換、の順に処理されます。

複数列のうち、日付列だけを文字列にする

複数列を返す場合は、まず日付値を含む表をHSTACKで作って重複削除と並び替えを済ませ、最後に日付列だけを文字列化します。次の例ではC列の日付とE～F列を1つの表にし、1列目の日付で昇順に並べます。

=LET( data,SORT(UNIQUE(HSTACK( FILTER('申込一覧'!C3:C14,'申込一覧'!D3:D14="対象"), FILTER('申込一覧'!E3:F14,'申込一覧'!D3:D14="対象") )),1,1), HSTACK( TEXT(CHOOSECOLS(data,1),"yyyy年m月d日"), CHOOSECOLS(data,2,3) ) )

HSTACKは、日付列と残りの列を横にくっつけ、1つの表にする働きです。LETで重複削除・並び替え済みの表を data と名付け、その1列目だけをTEXTで加工してから、2・3列目と再び横に並べています。

UNIQUEは行全体、SORTは指定列で判定
複数列の表をUNIQUEに渡すと、全列の組み合わせが完全に同じ行だけを重複として削除します。一方、SORT(...,1,1) は、完成した表の1列目を基準に昇順で並び替えます。

次の式では、「顧客一覧」シートのG列が「発送対象」の行をA～O列から抽出し、その15列すべてが同じ行だけを削除した後、1列目で並び替えます。

=SORT(UNIQUE(FILTER('顧客一覧'!A2:O100,'顧客一覧'!G2:G100="発送対象","")),1,1)

UNIQUEが効いていないように見えるときは、A～O列のどこかに違いがあります。余分なスペース、非表示の時刻、数値と文字列の違い、小数点以下の値なども別データとして判定されます。一部の列だけで重複を判定したい場合は、CHOOSECOLSで必要な列に絞ってからUNIQUEへ渡します。

=SORT(UNIQUE(CHOOSECOLS(FILTER('顧客一覧'!A2:O100,'顧客一覧'!G2:G100="発送対象",""),1,2,3)),1,1)
並び順とTEXT化の注意
年月日の文字列をSORTすると、書式によっては日付順にならない場合があります。上の式のように日付値でSORTしてからTEXT化するか、元の日付列とは別に表示用の文字列列を用意してください。また、時刻の違いも残したい場合は、TEXT化する前にUNIQUEを行います。

まとめ

UNIQUE、FILTER、SORTを組み合わせると、手作業で行っていた「フィルター」「重複の削除」「並び替え」を、数式1つで自動化できます。

=SORT(UNIQUE(FILTER('担当者一覧'!C3:C14,'担当者一覧'!D3:D14="対象")))

元データが増えても、条件付きの重複なしリストが自動で更新され、さらにきれいに並び替えられます。プルダウンリスト、担当者一覧、商品マスタ、対象顧客リストなど、実務でかなり使い回せる形です。

スピル関数の強さ
従来はボタン操作を何度も行っていた作業が、FILTER、UNIQUE、SORTのネストで「更新され続ける一覧」に変わります。VBAなしでここまで自動化できるのが、最新Excelの大きな魅力です。
