Power Queryで複数シートを1つにまとめる：シートが増えても更新だけで使える

月別や支店別に分かれたシートをコピーしてつなぐ作業を、Power Queryで自動にします。シートを足して「更新」を押すだけで、1つの表に反映されます。

💡 まず方法を選ぶ

まとめたいシートがどこにあるかで、使う方法が変わります。一覧にして使い回すなら、別ブックから読み込む方法が扱いやすくなります。

複数シートをまとめる方法
場面方法使える版
別のブックのシートをまとめる（おすすめ）Power Query（Excel.Workbook）Excel 2016以降
同じブックの中のシートをまとめる各シートをテーブルにして Power Query（Excel.CurrentWorkbook）Excel 2016以降

💡 集計用のブックを分ける理由
Excel.Workbook が読むのは、保存されたファイルの中身です。元データと集計を別のブックにすると、集計シートを読み込んで数字が二重になる事故を防げます。

📋 手順1：元のブックを確認する

ここでは、次のようなブックを例にします。

  • ファイル：C:\data\売上_2026.xlsx
  • シート：4月、5月、6月、入力例（まとめない）
  • どのシートも1行目が見出しで、列は「日付」「担当」「金額」

見出しの名前は、シートごとにそろえておきます。「金額」と「売上金額」のように違うと、別の列として扱われます。

🔄 手順2：シートの一覧を取り込む

  1. 集計用の新しいブックで、「データ」→「データの取得」→「ファイルから」→「Excel ブックから」を選びます。
  2. 元のブックを選び、「開く」を押します（版によっては「インポート」と表示されます）。
  3. ナビゲーターで、シート名ではなく一番上のブック名を選びます。
  4. 「データの変換」を押します。

シートの一覧が表になって、Power Queryエディターに表示されます。主な列は次のとおりです。

取り込まれる列
列内容
Nameシート名
Dataシートの中身（Table と表示される）
Kind種類（シートは Sheet）
Hidden非表示かどうか

画面の名前は、Excelの版によって少し異なる場合があります。ナビゲーターでブック名を選べないときは、シートを1つ選んで「データの変換」を押し、「適用したステップ」の「ナビゲーション」を削除すると同じ一覧になります。

✂️ 手順3：不要なシートを除いて、縦につなぐ

  1. 「Kind」列のフィルターで Sheet だけを残します。
  2. 「Hidden」列のフィルターで FALSE だけを残します。
  3. 「Name」列のフィルターで、まとめないシート（入力例など）のチェックを外します。
  4. 「列の追加」→「カスタム列」で、列名を「表」、式を Table.PromoteHeaders([Data], [PromoteAllScalars=true]) にします。各シートの1行目が見出しになります。
  5. 「Name」列と「表」列だけを選び、「列の削除」→「他の列の削除」を選びます。
  6. 「表」列の見出しの右にある展開ボタンを押し、「元の列名をプレフィックスとして使用します」のチェックを外して「OK」を押します。
  7. 「Name」列の名前を「月」に変え、日付や金額の列にデータ型を設定します。
  8. 「閉じて読み込む」で完了です。

同じ処理をM言語で書くと、次のようになります。詳細エディターに貼り付ける場合は、ファイルの場所と列名を実際のものに置き換えてください。

let
    ソース = Excel.Workbook(File.Contents("C:\data\売上_2026.xlsx"), null, true),
    シート = Table.SelectRows(ソース, each [Kind] = "Sheet" and [Hidden] = false and [Name] <> "入力例"),
    見出し = Table.AddColumn(シート, "表", each Table.PromoteHeaders([Data], [PromoteAllScalars=true])),
    列選択 = Table.SelectColumns(見出し, {"Name", "表"}),
    展開 = Table.ExpandTableColumn(列選択, "表", {"日付", "担当", "金額"}),
    列名 = Table.RenameColumns(展開, {{"Name", "月"}})
in
    列名

🔁 シートが増えたとき

元のブックに「7月」シートを足して保存し、集計用のブックで「データ」→「すべて更新」を押します。シート名を指定していないので、新しいシートも自動で加わります。

⚠️ 列を増やしたときは展開の設定も直す
展開する列名は固定で記録されます。あとから「備考」列を足しても、そのままでは表に出ません。「適用したステップ」の展開のステップを開き直して、列を追加します。

⚠️ つまずきやすい点

よくある症状と確認すること
症状原因対処
金額が2倍になる集計シートや合計用のシートも読み込んでいる「Name」列のフィルターで除外します。
見出しが列名にならない1行目にタイトルがある式を Table.PromoteHeaders(Table.Skip([Data], 2), [PromoteAllScalars=true]) のようにして、見出しまでの行を飛ばします（2は飛ばす行数）。
値が null の列があるシートによって見出しの名前が違う元のシートの見出しをそろえます。
途中に見出しの行や空行が混ざる表の途中に見出しや合計がある「日付」列などのフィルターで、不要な行を除きます。
日付が 46113 のような数値で表示されるデータ型を設定していない日付の列のデータ型を「日付」にします。
月の順に並ばない元のブックのシートの順に並ぶシートの順をそろえるか、日付の列で並べ替えます。
ファイルの場所を変えたらエラーになる読み込み元のパスが変わった「データの取得」→「データ ソースの設定」で変更します。

取り込んだ後は、月ごとの行数を元のシートと比べると、読み込み漏れや二重計上に気づきやすくなります。

検証環境：Windows版 Excel（バージョン16.0、ビルド20625）、2026年11月4日。手順2の画面、この記事のM言語の式、シートの追加と更新、非表示シートの除外、数式の例を架空のブックで確認しました。手順3の画面操作はM言語の式で確認しています。Excel 2016・2019では確認していません。

📎 同じブックの中でまとめたいとき

Power Queryの Excel.CurrentWorkbook が読めるのは、テーブルや名前付き範囲で、シートそのものは読めません。先に各シートの表をテーブルにします。

  1. 各シートの表を選び、Ctrl+T でテーブルにします。
  2. 「テーブル デザイン」タブで、名前を「売上_4月」「売上_5月」のように付けます。
  3. 「データの取得」→「その他のデータ ソースから」→「空のクエリ」を選び、詳細エディターに次の式を入れます。
let
    ソース = Excel.CurrentWorkbook(),
    対象 = Table.SelectRows(ソース, each Text.StartsWith([Name], "売上_")),
    結合 = Table.Combine(対象[Content])
in
    結合
⚠️ 結果のテーブルの名前に注意
読み込んだ結果のテーブルは、同じブックの中のテーブルになります。その名前が「売上_」で始まると、更新のたびに結果まで読み込んでしまいます（検証では、更新のたびに4行→6行→8行と増えました）。「集計結果」のように別の名前にしてください。

🧮 数式で済ませる方法

合計だけ分かればよいときは、3D参照が手軽です。シート名の間のシートがすべて対象になります。

=SUM('4月:6月'!C2:C100)

Excel 2024 / Microsoft 365 では、VSTACKで一覧にできます。空行は FILTER で除きます。

=LET( 表, VSTACK('4月:6月'!A2:C100), FILTER(表, INDEX(表,,1)<>"") )
数式とPower Queryの違い
数式Power Query
結果の反映自動で再計算「更新」を押す
シート名の列を付ける工夫が必要「Name」列で簡単
行数が多いとき重くなりやすい更新のときだけ処理する
整形やデータ型の設定式が長くなるステップとして残る
