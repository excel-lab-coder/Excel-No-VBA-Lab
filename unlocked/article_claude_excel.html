Claude in Excel
できること・使用量・対応Excel

「この数値はどのセルから来たのか」「前提を変えるとどこに影響するのか」。Excelの中でClaudeに相談しながら、表や数式を確認する方法です。既存のClaude契約をExcel作業にも活用できます。

公式資料に基づく導入ガイドです

「Claude in Excel」として知られる機能は、確認日時点の公式文書ではClaude for Excel、配布ページではClaude for Microsoft 365と案内されています。本記事の依頼例は当サイトの練習案であり、各Excel版でのインストール・AIによる編集の実機検証は未実施です。

1. 開いたブックを見ながら、説明と編集を頼める

Claude for Excelは、開いているブックへの質問、数式エラーの原因調査、モデルやテンプレートの作成を支援するアドインです。説明には参照セルへのリンクが付くため、自分でも根拠をたどれます。Claude公式ガイド

公式配布ページでは、複数シートを読んで数式のある表を作り、変更したセルを追跡する使い方が紹介されています。Excel・Word・PowerPoint間で会話を引き継ぐ使い方もあります。アプリをまたぐ連携は、必要なアドインと利用権限を確認してから使います。Claude for Microsoft 365公式配布ページ

最初から大きな業務ブック全体を任せる必要はありません。「まず説明だけ」「このシートだけ」「この入力セルだけ」と範囲を絞ると、人が確認しながら進めやすくなります。

2. 導入と対応するExcel

  1. 公式配布ページで「Claude for Microsoft 365」と提供元を確認します。
  2. 社内でアドインと外部AIの利用が許可されていることを確認して追加します。
  3. Excelでアドインを開き、対象のClaudeアカウントでサインインします。
  4. 練習用ブックで「まだ変更せず、シート名と表の範囲を説明してください」と依頼します。

公式の対応条件は、Web版Excel、WindowsのMicrosoft 365版（ビルド16.0.13127.20296以降）、Mac版（16.46／ビルド21011600以降）です。WindowsのExcel 2016／2019買い切り・ボリュームライセンス版、iPad、Androidなどは非対応とされています。公式対応条件

「Office 365以外は全部できない」ではなく、OS・版・用途を分ける

WindowsのアドインはMicrosoft 365契約が対応条件です。一方、MacやWebは別の条件で記載されています。Windows買い切り2021／2024についても、本記事では対応を保証しません。ChatGPTの買い切り版対応も、今回の資料だけでは確定できません。両製品の対応環境比較表を確認してください。

なお、アドインを使わず、Claudeのチャットで.xlsxを作成してダウンロードする機能もあります。これはExcel内で動くアドインとは別です。買い切り版でファイルを開く場合は、出力された数式・機能がその版に対応するかを確認します。Claudeでファイルを作成・編集する公式説明

3. サブスク内で使えるが、Claude Codeやチャットと使用量を共有する

Claude for Excelの対象はPro／Max／Team／Enterpriseです。個人向けPro／Maxなら、契約に含まれる使用枠で利用できます。アドイン用に別のClaudeサブスクを契約する必要はありませんが、Excelの利用権は別です。組織契約は座席・従量課金の条件を確認します。対象プランと使用量

2026年10月9日現在：同じアカウントの使用枠を使う

Excelでの利用もClaudeアカウントの上限に計上されます。公式ヘルプでは、Claudeのチャット、Claude Code、Claude Desktop等の使用量は同じ上限に合算されると説明しています。使用量の公式説明

たとえばClaude Codeで長い作業をした後は、Excel側で使える残量も意識します。これは「どの画面でも1回の依頼が同じ消費量」という意味ではありません。ブックの大きさ、会話の長さ、モデル、処理の複雑さなどで変わります。新しい会話を開いても、アカウントの使用上限がリセットされるわけではありません。

サブスク内に収めたい場合は、利用状況を見ながら対象範囲を絞って依頼し、上限に達したら回復を待ちます。追加の使用クレジットを有効にして続行すると、サブスクとは別料金になります。自動購入や利用上限の設定も確認してください。追加クレジットの公式説明

4. 本編の数式を使って「参照関係の説明」を試す

ここではChatGPT記事の練習データと同じ3行の架空売上を使います。データと期待する答えを揃えると、両方の使い勝手を比較しやすくなります。個人情報や実際の売上データは不要です。

手順A：小さな表を自分で作る

  1. A1:C4に「店舗・数量・単価」のデータを入力します。
  2. D1を「金額」とし、D2に=B2*C2を入力してD4までコピーします。
  3. F1を「店舗」、G1を「合計」とし、F2に「東店」、F3に「西店」を入力します。
  4. G2に=SUMIFS($D$2:$D$4,$A$2:$A$4,F2)を入力し、G3までコピーします。

期待する結果は東店3600、西店1500です。式の考え方は本編のCOUNTIFS・SUMIFSの記事で確認できます。AIを使わなくても取り組める課題です。

手順B：変更せず、説明を依頼する

この練習用ブックのG2の計算を説明してください。
どの店舗の、どの行の金額が集計されているか、参照セルを示してください。
その金額の元になった数量と単価までたどってください。
まだセルの値や式は変更しないでください。

東店の明細は2行目と4行目、金額はD2とD4です。説明の文章だけでなく、案内されたセルを開いて確認します。

手順C：変更範囲を絞って依頼する

練習用データのC2の単価だけを1200から1500へ変更したいです。
変更前に、影響するセルと予想される結果を説明してください。
承認するまでは変更しないでください。
D列とG列の数式は値に置き換えず、そのまま残してください。

人が照合する結果はD2が3000、G2が4200、西店は1500のまま、全体では5700です。説明を確認して変更を承認した後、数式が残っていることも確かめます。この依頼例でのClaudeの実行結果は未検証です。

本編の他の記事と組み合わせるなら

  • XLOOKUP基本編：検索値が見つからない理由と、検索範囲を説明してもらう。
  • LAMBDA入門：複雑な式を、途中計算に名前を付けた説明へ整理してもらう。提案式は対象Excelで再検証する。

AI・アドインが禁止されている環境では、本編の式を手動で確認してください。外部AIの利用許可とVBAの利用許可は別です。

5. ChatGPTとどちらを使う？

どちらも、Excelを離れずに相談や編集を進められる点が便利です。既にChatGPT Plus／Proを使っているならChatGPT、Claude Pro／Maxを使っているならClaudeから試すと、手持ちの契約を活用できます。両方の契約が必須という意味ではありません。

使用量の違いは、「Claudeは合算、GPTは完全に独立」と単純化しないことが大切です。Claudeはチャット・Code等と共有し、ChatGPT for ExcelもPlus／ProではCodexなどのエージェント使用枠を共有します。通常チャットの上限と、エージェント機能の上限を分けて確認してください。OpenAI公式料金資料、Claude公式の使用量説明

当サイトでは、同じ架空データで「説明が理解しやすいか」「変更範囲を守るか」「式が残るか」「確認・修正がしやすいか」を比べる使い方を提案します。性能や速さの優劣を示す比較実験を行った記事ではありません。

ChatGPT／Claudeの比較表と対応Excelの比較表もあわせて確認できます。

6. できないことと、業務利用前の確認

公式文書では、データテーブル（What-if分析）とVBA／マクロ操作は非対応です。制限解除ラボに掲載していますが、Claudeのアドインを入れるだけでVBA自動化まで可能になるという意味ではありません。公式の制約

  • データの扱い：アドインはブックを読み書きし、インターネットへデータを送信できます。会社の許可を確認し、練習には架空データを使います。配布ページのアクセス権限
  • 原本を守る：コピーで試し、編集対象・数式・件数・集計値を確認してから採用します。
  • 外部ファイル：ファイル内の文章に、意図しない操作へ誘導する指示が紛れている可能性があります。不明な送信先や不要な変更は承認しません。公式の注意事項
  • 検証記録：導入日、Excelの製品名・OS・ビルド、Claudeプラン、試した課題と結果を残すと、更新後の比較がしやすくなります。
