本編で“あと一歩”だった処理のVBA補完集

計算やデータ整形は関数・Power Queryに任せ、VBAは「選ぶ」「出す」「固定する」「記録する」に限定します。短いコードでも、責任範囲を狭くすると保守しやすくなります。

サンプルの前提：このブックに「帳票」「結果」「実行ログ」の3シートを用意します。「実行ログ」は1行目を見出し行にしてください。
実行前に

必ずコピーしたブックとテスト用フォルダで確認してください。掲載コードは汎用例であり、保護シート、権限、既存ファイル、PDFプリンター設定など、利用環境による差があります。

1. VBAを使う範囲を先に決める

処理基本担当VBAの役割
集計・検索・判定関数原則なし
取込・結合・整形Power Query必要なら更新開始のみ
PDF・ファイル出力VBA保存先とファイル名を制御
操作履歴VBA実行日時・利用者・結果を追記

2. パターンA：利用者に保存先フォルダを選んでもらう

パスをコードへ固定せず、実行時に選択します。キャンセルは正常な終了として扱います。

Private Function 保存先を選ぶ() As String
    With Application.FileDialog(msoFileDialogFolderPicker)
        .Title = "保存先フォルダを選択してください"
        .AllowMultiSelect = False
        If .Show <> -1 Then Exit Function
        保存先を選ぶ = .SelectedItems(1)
    End With
End Function

3. パターンB：指定シートをPDFへ出力する

数式やPower Queryで完成した帳票を、最後だけVBAでPDF化します。同名ファイルがある場合は上書きせず停止します。

Public Sub 帳票をPDF保存する()
    Dim folderPath As String, pdfPath As String
    Dim ws As Worksheet

    Set ws = ThisWorkbook.Worksheets("帳票")
    folderPath = 保存先を選ぶ()
    If Len(folderPath) = 0 Then Exit Sub

    pdfPath = folderPath & "\帳票_" & Format$(Now, "yyyymmdd_HHMMSS") & ".pdf"
    If Len(Dir$(pdfPath)) > 0 Then
        MsgBox "同名ファイルが存在するため中止しました。", vbExclamation
        Exit Sub
    End If

    ws.ExportAsFixedFormat Type:=xlTypePDF, _
        Filename:=pdfPath, Quality:=xlQualityStandard, _
        IgnorePrintAreas:=False, OpenAfterPublish:=False
    実行ログを書く "PDF出力", pdfPath, "成功"
End Sub

印刷範囲、改ページ、余白、非表示行はExcel側の設定に従います。PDF化前に印刷プレビューで確認してください。

4. パターンC：計算結果を値として別シートへ残す

数式を壊して上書きするのではなく、新しいシートへ値だけを複製します。監査証跡として使う場合は、保存ルールと改変権限も別途必要です。

Public Sub 結果を値で保存する()
    Dim src As Worksheet, dst As Worksheet
    Dim newName As String

    Set src = ThisWorkbook.Worksheets("結果")
    newName = "確定_" & Format$(Now, "mmdd_HHmmss")

    Set dst = ThisWorkbook.Worksheets.Add( _
        After:=ThisWorkbook.Worksheets(ThisWorkbook.Worksheets.Count))
    dst.Name = newName
    src.UsedRange.Copy
    dst.Range("A1").PasteSpecial xlPasteValuesAndNumberFormats
    Application.CutCopyMode = False
    実行ログを書く "値の確定", newName, "成功"
End Sub
注意：シート名は31文字までです。同じ秒に再実行した場合やブック構成によっては名称が重複するため、本番では重複確認を加えてください。

5. パターンD：最低限の実行ログを残す

「いつ、誰が、何を、どう終えたか」をログシートへ追記します。Windowsの利用者名だけで本人性を保証できるわけではありませんが、調査の手掛かりになります。

Private Sub 実行ログを書く(ByVal actionName As String, _
                            ByVal target As String, _
                            ByVal result As String)
    Dim ws As Worksheet, nextRow As Long
    Set ws = ThisWorkbook.Worksheets("実行ログ")
    nextRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row + 1

    ws.Cells(nextRow, 1).Value = Now
    ws.Cells(nextRow, 2).Value = Environ$("Username")
    ws.Cells(nextRow, 3).Value = actionName
    ws.Cells(nextRow, 4).Value = target
    ws.Cells(nextRow, 5).Value = result
End Sub

失敗時も記録したい場合は、各処理にエラーハンドラーを設け、エラー番号と説明をログへ残します。機密パスや個人情報をログへ書き過ぎないことも重要です。

6. 採用判断

  • 複数人がコードを読めるか
  • 失敗時に元へ戻せるか、またはバックアップがあるか
  • 処理対象と出力先を画面で確認できるか
  • 上書きを既定動作にしていないか
  • 関数やPower Query側へ戻して簡単にできないか

まとめ

制限解除ラボのVBAは、すべてをマクロ化するためではありません。関数・Power Queryで作った安定した処理に、出力や記録という最後の一手だけを加える使い方が基本です。
